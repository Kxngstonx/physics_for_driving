# 새 모델 설계 (11/25, `shinyoung`)

목표: R1–R6(베이스라인)보다 **속도 예측 오차(vx, vy, r)**가 낮은 모델. MPPI 에서 쓸 수 있을 만큼 빨라야 하고,
나중에 "예측이 정확한 모델일수록 주행도 잘하는가"를 MPPI 랩으로 시험한다.

## 1. 비교 조건 (R1–R6 과 같음)
- 분할·설정: 팀원 분할, `GOLF_THUNDERHILL_G` (m 1496.9, 앞 제동 몫 0.75, 경사 채널, 좌우 기울기 0)
- 학습 규칙: `train.fit` 그대로 (1초 롤아웃 손실, 최대 300 에폭, 조기 종료 25, 학습률 감소 10), 시드 0·1·2
- 평가: 팀원 `evaluate.py` (시험 10_1·11_1·11_5, 0.04 / 0.2 / 0.48 / 1.0 s RMSE). 모델 이름 `[RN]?_s?_roll25` 를 모두 평가
- 형식: hist (B, 8, 7) → 다음 [vx, vy, r]. `ladder.build("N1", cfg)` 로 만들고 MPPI·평가 코드는 고치지 않음

## 2. 모델 (단계마다 하나씩 더해 효과를 나눠 본다)

| | 모델 | 더하는 것 | 가설 |
|---|---|---|---|
| N1 | P2 물리 | R1 대신 P2 식: 타이어 최대 힘 μ·Fz, 앞뒤 하중 이동, 마찰원, RK4 (0.02 s × 2). 계수 11개 전역, 초기값 = P2 피팅 | 물리 뼈대가 강하면 R1 보다 낫다 |
| N2 | N1 + 힘 보정 | MLP(이력 8스텝) → 보정 가속도 [Δax, Δay, Δṙ] 를 미분 식 안에 더함 (적분을 거침). 처음엔 N1 과 같음 | 단위가 맞는 자리에 보정하면 R2(상태에 직접 더함)보다 낫다 |
| N3 (예정) | N2 + 긴 기억 | GRU 로 과거 1~2 s 요약 → 보정 MLP 입력 | 천천히 변하는 숨은 상태(타이어 온도, μ) |
| N4 (예정) | 학습 개선 | 롤아웃 25 → 50, D1 사전 학습, 시드 앙상블 | 같은 모델을 더 잘 학습 |

N3 은 과거 길이가 8보다 길어 MPPI(`mppi.H = 8`)와 평가 시작점을 함께 바꿔야 한다. 그때 공통 시작점 평가를 따로 만든다.

## 3. 지금까지 확인 (로컬 CPU)
- N1 = P2 시뮬레이터 (같은 계수·0.01 s 에서 차이 < 1e-8), RK4 2번(0.02 s)과 8번 차이 < 1e-4
- 학습 전 N1 (P2 피팅값 그대로), 시험 주행 1초: vx 0.263, vy 0.284, r 0.043 (현재값 유지: 1.85 / 0.44 / 0.148)
- 3 에폭 시험 학습 검증 손실: N1 1.53 (0 에폭에서 이미 최저), N2 1.254, R2 1.257 — 본 학습은 Colab
- 계산 시간 (후보 1024개, 한 스텝, CPU): R1 3.8 ms, R2 5.7, R4 7.0, R5 2.1, N1 11.4, N2 12.7. GPU·MPPI 에서 다시 잼
- 시험: `tests/golf/test_hybrid.py` (P2 와 같음, N2 시작 = N1, 저장·불러오기, 오르막 효과)
