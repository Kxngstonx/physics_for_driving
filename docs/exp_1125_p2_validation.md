# 11/25 실험: P2 시뮬레이터 모델 없는 운전자 검증

시뮬레이터 자체와 계수 맞추기는 [`p2_sim.md`](p2_sim.md), 이 문서는 그 위에서 한 랩 검증과 조향 지연 판단.

## 1. 무엇을, 왜

- 1초 롤아웃 오차(`fit_p2.py`)는 기록 입력을 넣고 짧게 굴렸을 때만 본다.
- 실제 실험에서는 MPPI 가 시뮬레이터 안에서 한 바퀴를 몰고, 그 랩타임으로 모델(R1–R6)을 비교한다. 그래서 한 바퀴를 몰아도 실제 차와 같은 결과가 나오는지 따로 확인한다.
- 학습 모델로 몰면 결과가 틀렸을 때 모델 탓인지 시뮬레이터 탓인지 구분이 안 된다. 그래서 고전 제어기(모델 없는 운전자)로 몬다.

판정: 기록 주행선·기록 속도를 따라 돌았을 때 랩타임이 기록 랩 ±2% 이내.

## 2. 방법 (`experiments/golf/validate_sim.py`, `drive_free`)

| | 내용 |
|---|---|
| 세계 | `p2.P2World.from_fit()` (`results/sim/p2_fit.json`), 경사는 위치별, 브레이크 지연 35 ms + 1차 20 ms (팀원 `fit_delays.py`) |
| 트랙 | 기록 주행선 (각 랩의 실제 경로), 이탈 = 경계 밖 0.9 m |
| 조향 | pure pursuit (앞 0.8 s 지점) + 언더스티어 보정 (P2 선형 강성) + 횡오차 PI |
| 속도 | 위치별 기록 속도를 목표로 PI + 저항·경사·속도 변화 앞먹임 |
| 출발 | 기록 랩과 같은 위치, 같은 속도 (정지 출발) |

운전자 게인 중 `prev_t`(목표 속도를 몇 초 앞에서 볼지)와 `kp_v`(속도 게인)는 데이터로 고르므로 랩을 둘로 나눴다.
- 튜닝 랩 2023-10_5: 3 × 3 격자에서 기록에 가장 가까운 설정을 고른다.
- 검증 랩 2023-10_8: 고른 설정 그대로, 조향 지연 4가지(0, 0.04, 0.08, 0.12 s)로 돈다.

```
python experiments/golf/fit_p2.py
python experiments/golf/validate_sim.py closed_free p2     # → results/sim/validation.json 의 closed_free_p2
```

검증 랩은 튜닝에 쓰지 않은 랩이므로, 맞은 것이 게인을 맞춘 덕은 아니다.

### 처음 돌렸을 때 −3.4% 였던 이유 (고침)
- 증상: 9개 설정 모두 기록보다 3.4% 빨랐다. 구간별로 보면 첫 10% 구간만 2.3 s 빨랐고 나머지는 오히려 조금 느렸다.
- 원인: `recorded_track` 이 기록 속도를 위치별로 모을 때 랩 앞/뒤 절반을 트랙 번호 0 기준으로 나눴다. 두 랩 모두 이음매 직전(10_5 는 2614/2620, 10_8 은 2602/2620)에서 출발해서, 출발 지점의 목표 속도가 랩 끝 속도 32 m/s 가 됐다. 정지 출발 대신 달리며 출발한 셈이다.
- 고침: 실제 출발 위치에서 잰 거리로 나눈다. 출발 목표 속도가 0.8·1.2 m/s 로 돌아왔다.
- 팀원 CommonRoad 세계 검증도 같은 함수를 써서 같은 오차가 있었을 수 있다.

## 4. 조향 지연을 0 으로 두는 것

결론: **본 실험은 0 으로 두되, 결과를 낙관적인 쪽으로 읽고 MPPI 로 0.04 s 민감도 확인을 따로 한다.**

0 이 맞는 쪽 근거
1. **데이터로 정할 수 없다.** D7 에는 조향 명령 열이 없고 실제 바퀴각(`roadWheelAngle_rad`)만 있다. 브레이크·엔진은 명령 열(`brakeCmd_*`, `throttleCmd_percent`)이 있어 `fit_delays.py` 가 지연을 맞췄지만 조향은 못 한다. `fit_delays.py` 의 규칙("데이터로 정해지지 않은 지연은 넣지 않는다")을 따르면 0 이다.
2. **모델 입력과 기준이 같다.** R1–R6 학습 입력도, P2 계수 맞추기 입력도 측정 바퀴각이다. 즉 이 프로젝트에서 "조향 명령" = 바퀴각 그 자체이고, 명령 → 바퀴각 사이에 지연을 넣으면 학습 데이터에 없는 지연이 새로 생긴다.
3. **완전히 0 은 아니다.** 세계는 바퀴각을 0.04 s 동안 일정한 속도로 목표까지 옮기므로(평균 약 0.02 s 늦음), 운전자도 한 스텝 조향 변화가 0.02 rad 로 제한된다. 타이어가 힘을 내기까지의 늦음은 1초 롤아웃으로 맞춘 계수에 흡수돼 있다.
4. **모델 비교는 공정하다.** 모든 모델이 같은 세계에서 달리므로, 지연 값이 모델 순위를 한쪽으로 기울이지는 않는다.

조심할 점
- 실제 차에는 조향 모터 지연이 있다(값 미상). 0 으로 두면 랩타임·이탈 횟수가 실제보다 낙관적일 수 있다.
- 0.04 s 만 넣어도 이 운전자는 이탈했다. 다만 이 운전자는 지연을 미리 보상하는 기능이 없는 단순 제어기라, 세계가 지연에 민감하다는 증거라기보다 운전자의 한계에 가깝다. MPPI 는 앞을 예측해 계획하므로 다를 수 있다.
- 할 일: B 방식 실험에서 모델 한두 개로 조향 지연 0.04 s 를 넣은 세계도 돌려, 순위가 유지되는지 본다 (`make_world(delays=dict(steer=0.04))`).
