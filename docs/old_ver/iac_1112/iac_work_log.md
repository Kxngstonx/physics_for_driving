# IAC 레이스카 사다리 + 제어 주행 비교 작업 기록 (2026-11-12 밤)

## 목표 (석우 결정, 11/12)
- 자율주행 **제어 주행 비교**. 실차 데이터는 IAC 레이스카(Deep Dynamics 공개 데이터)
- 가상 세계 여러 개를 함께 사용, 물리 비중 사다리 전체(R1~R6) 비교

## 진행 중 발견하고 고친 것
1. **뱅크(트랙 경사)**: 처음엔 뱅크 없이 학습 → 모든 모델의 조향 반응이 실제의 약 1/5 (40 m/s에서 delta 0.01 → r 0.03 vs 데이터 약 0.15). LVMS는 경사진 오벌이라 경사가 선회를 거듦. 데이터 roll 열이 LVMS에서 −0.16~−0.35 rad(경사로 보임)라 뱅크로 사용. Putnam의 roll 열은 ±1.6 rad로 망가져 있어 0으로 둠 [추정: Putnam은 평지에 가까움]
2. **물리 모델 1스텝 적합이 나쁨**: 1스텝 오차가 현재값 유지보다 vy 6배·r 2배 큼. 측정 vy가 강하게 평활된 추정값으로 보임(1스텝 변화 표준편차 0.013 m/s) [추정]. 센서 위치 보정 계수 `ds`를 넣었지만 크게 나아지지 않음. 단, 1초 연속 예측에서는 R1이 현재값 유지보다 r 오차가 작음 (임시 모델 기준)
3. **검증 주행 LVMS_B가 저속(≤21 m/s)이라 조기 종료 기준으로 부적합** → 마지막 에폭 모델 저장으로 바꿈
4. **R1은 초기값이 고정이라 시드 3개가 사실상 같은 모델** (기록)
5. **MPPI 파이썬 오버헤드**: R1 기준 제어 1번에 250 ms → CUDA 그래프로 18 ms (결과 동일 확인)
6. **세계 모델이 5 m/s 아래로 내려가면 학습 범위 밖** → vx < 3 m/s면 "정지"로 기록하고 종료
7. **1스텝 학습한 물리 모델(R1)의 계수가 비현실적**: 300 에폭 뒤 앞·뒤 타이어 최대 힘 1546·1148 N(최대 횡가속 약 0.35 g), Iz·ds가 범위 끝에 붙음. 평활된 vy의 1스텝 변화에 맞추려다 타이어를 약하게 만든 것으로 보임 [추정]. 이대로 세계로 쓰면 LVMS 커브(필요 횡가속 약 14 m/s²)를 어떤 제어기도 못 돎
   - 1초(25스텝) 연속 예측 손실로 학습하니 Df 5851·Dr 7691 N, ds 0.49 m로 현실적이 되고 1초 vy 오차 0.45 → 0.16 (시험 주행)
   - 결정: **가상 세계 3개(R1·R4·R5)는 25스텝 연속 예측 손실로 학습**(`*_world_roll`, 40 에폭). 비교 대상 사다리는 논문 방식(1스텝) 그대로
   - 결과 해석 시 주의: 물리 계열 제어 모델(R1~R4)의 1스텝 학습 계수는 위처럼 비현실적일 수 있음
